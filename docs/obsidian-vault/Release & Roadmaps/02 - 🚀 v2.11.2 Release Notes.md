# 🚀 FormEase Pro v2.11.2 Release Notes

**Release Date**: August 17, 2026  
**Build Target**: Windows x64 (`.exe`), macOS Universal (`.dmg`), Web SPA

---

## 🌟 Highlights & Key Improvements

1. **Intelligent Subject Normalization**:
   - Integrated `normalizeSubjectName` into section subject filtering (`rbac.ts`).
   - Automatically synchronizes custom subject variants (`Filipino 10` $\rightarrow$ `Filipino`) with canonical curriculum templates.

2. **E-Class Record Self-Healing Grid**:
   - `EClassRecord.tsx` and `ShsEClassRecord.tsx` now match student grades and HPS criteria across composite IDs, canonical names, and store lookups.
   - Fixed empty quarter dropdown bug and missing student grade rows.

3. **Startup Database Reconciler**:
   - `initializeAppStore` backfills missing `subject_name` attributes in IndexedDB on application launch.

4. **Production Security Shields**:
   - Obfuscated desktop production runtime (`dist-electron/main.cjs`, `license.cjs`, `preload.cjs`).
